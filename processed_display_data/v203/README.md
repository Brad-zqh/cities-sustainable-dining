# Processed display data: V203 snapshot

52 field-reviewed empirical display files, with hashes in `manifest.json` and
`SHA256SUMS.csv`. `field_dictionary.csv` covers every released field, its unit,
meaning and missing-value rule. This folder is public processed display data.

See [scope, version, figure/table mapping, provenance and CRS](../../docs/PROCESSED_DISPLAY_DATA.md).
Run the guarded `scripts/reproduce_display.py` from the repository root for
V203 Figs. 12–19 and SI Fig. S9. Run `scripts/build_display_tables.py` for the
selected numerical SI results. Data and code do not rerun the original models.

Author release authorisation applies to these processed display inputs.
No new third-party data licence, DOI or raw-data publication is asserted.
