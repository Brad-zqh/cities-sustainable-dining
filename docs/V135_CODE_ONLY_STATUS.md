# V135 code-only status

This update publishes source code and synthetic tests for three parts of the
revised analysis: annual dish-mention aggregation, bounded nutrition scoring
and legacy deletion auditing, and external benchmark bookkeeping. It does not
publish platform records, menu or review images, restaurant-level outputs,
licensed spatial inputs, manuscripts or final empirical figures.

The revised six-domain neighbourhood index is presented as exploratory.
Computational consistency and synthetic unit tests do not establish construct
validity. Independent validation and empirical-data redistribution clearance
remain separate requirements. The code here should not be interpreted as a
claim that all V135 results or figures can be reproduced from this repository
alone.

The historical figure renderers remain available for authorized users with
the separately cleared input bundle. In the manuscript, quantitative V135
panels were regenerated from revised calculations with the historical visual
design; some newer workflow schematics are illustrative, not result maps.
